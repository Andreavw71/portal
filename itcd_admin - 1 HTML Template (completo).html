1Visão geral — componentes, eventos e tabelas

A solução é composta por 2 widgets do Service Portal e 3 tabelas, tudo em escopo Global (a instância não permite aplicativo com escopo próprio):

ComponenteIdentificaçãoFunção
Widget Simuladorid simulador_itcd · página simulador_itcd · portal swpCálculo do ITCD (herança e doações), impressão, avaliação por estrelas
Widget Painel Administrativoid itcd_admin · página itcd_adminManutenção mensal de UPF/SELIC; consulta de simulações e avaliações; protegido por senha

Cada tipo de evento grava numa tabela própria. A gravação é feita pelo Server Script dos widgets (GlideRecord) — roda no servidor da instância, sem credenciais no navegador:

EventoOrigemTabela de destino
Simulação (cálculo executado)Simuladoru_itcd_simulacao
Avaliação (estrelas + comentário)Simulador (rodapé)u_u_itcd_avaliacao
Índice mensal (UPF e SELIC)Painel Administrativou_ndice_upf_e_selic

A tabela u_ndice_upf_e_selic é a FONTE ÚNICA dos índices — o código não tem mais série embutida. A tabela deve conter a série completa (1999-01 até o mês vigente); a carga inicial é feita pela planilha UPF_SELIC_alimentacao.xlsx via "Colar do Excel" no Painel Administrativo. Se a tabela estiver vazia ou inacessível, o simulador exibe um aviso e não calcula.

2Tabelas e campos — passo a passo de criação e inclusão

Situação atual da instância: as três tabelas já existem, com estes nomes reais (o ServiceNow gerou os nomes a partir dos labels digitados):

FunçãoName real na instânciaSituação
Índices UPF/SELICu_ndice_upf_e_selicEm uso — conferir se a coluna u_selic existe
Log de simulaçõesu_itcd_simulacaoCriada — incluir as colunas abaixo
Avaliaçõesu_u_itcd_avaliacaoCriada — incluir as colunas abaixo

As tabelas u_x_sfmt_itcd_indice_upf (app antigo travado) e u_indice_selic não são usadas — ignorar.

Por que os nomes saíram "duplicados"Ao criar tabela/coluna, o ServiceNow adiciona o prefixo u_ ao que você digita no Label. Digitando o label já com u_, sai u_u_.... Regra prática: digite labels sem u_ e sempre confira o campo Column name antes de salvar — ele é editável na criação. Os Server Scripts já foram ajustados para os nomes reais acima.

2.0 — Como incluir UMA coluna (procedimento-base, vale para todas)

  1. Abra a lista da tabela pela URL direta: /u_itcd_simulacao_list.do (ou /u_u_itcd_avaliacao_list.do, /u_ndice_upf_e_selic_list.do).
  2. Clique com o botão direito em qualquer cabeçalho de coluna → Configure → Table. Abre o registro da tabela com a lista Columns.
  3. Na lista Columns, clique New.
  4. Preencha nesta ordem:
    • Type — escolha primeiro (String, Decimal, Integer ou True/False), pois o formulário muda conforme o tipo;
    • Column label — digite sem u_ (ex.: tipo_fato);
    • Column name — confira/edite para ficar exatamente como na tabela abaixo (ex.: u_tipo_fato);
    • Max length — só para String, conforme a tabela.
  5. Submit. Repita para a próxima coluna.

Alternativa pelo menu: All → System Definition → Tables → abrir a tabela → aba Columns → New (mesmo formulário).

4Páginas e portal

  1. Criar a página: All → Service Portal → Pages → New. Título e ID: simulador_itcd (simulador) e itcd_admin (painel).
  2. Colocar o widget na página: abra a página no Designer (All → Service Portal → Service Portal Configuration → Designer → selecione a página), arraste um container e, dentro dele, o widget correspondente. Salva automaticamente.
  3. URL de acesso: o portal desta instância é swp — as páginas ficam em https://sefazmtdev.service-now.com/swp?id=simulador_itcd1 e .../swp?id=citcd_admin. A forma infalível de obter a URL certa: no Designer, clique no ícone "Open in new window" (canto superior direito) e copie o endereço.
  4. Acesso às páginas: exige login na instância (Conecta). Não preencha o campo Roles do registro da página do painel com admin — isso bloquearia o mantenedor dos índices, que não é admin. O controle de acesso do painel é a senha (seção 5).

5Senha do Painel Administrativo

  1. Criar a propriedade: All → System Definition → System Properties → New. Preencha: Name = x_itcd.admin_senha · Type = string · Value = a senha escolhida. Salve.
  2. O Server Script do painel lê essa propriedade automaticamente. Enquanto ela não existir, vale a senha padrão gravada no código (ALTERE_ESTA_SENHA) — troque ou crie a propriedade antes de divulgar o painel.
  3. Como funciona: a senha é conferida no servidor a cada ação; os dados só são carregados se a senha bater; o navegador nunca recebe a senha de volta. Há botão Sair.
  4. Quem precisa de quê: o mantenedor dos índices precisa apenas de login no Conecta + link da página + senha. Nenhum papel de admin ou desenvolvedor. A gravação nas tabelas é feita pelo Server Script (acesso de sistema, escopo Global) — não requer ACL para o usuário.
Nível de proteção — leitura honestaA senha barra o usuário comum do portal, que é o alvo real: quem não tem perfil de desenvolvedor não abre o Widget Editor e não vê o Server Script. Quem tem acesso de desenvolvedor à instância consegue ver a senha se ela estiver no código — por isso a System Property é o modo recomendado (visível só a admins).

6Manutenção mensal dos índices (rotina do mantenedor)

  1. Obter no site do Sicalc o acumulado SELIC do mês e calcular a taxa do mês (diferença dos acumulados). Obter a UPF/MT vigente divulgada pela SEFAZ.
  2. Abrir .../swp?id=citcd_admin → digitar a senha → aba Índices UPF/SELIC.
  3. Preencher Mês (formato AAAA-MM), UPF (R$) e SELIC do mês (%) → Incluir / Atualizar.
  4. Conferir a linha na lista logo abaixo. Incluir o mesmo mês novamente atualiza o registro (não duplica). O botão Remover exclui um mês lançado errado.
  5. Vários meses de uma vez (colar do Excel): na mesma aba, use a caixa "Colar do Excel" — selecione na planilha as 3 colunas (Mês, UPF, SELIC), Ctrl+C, cole na caixa (Ctrl+V) e clique Importar lote. Aceita mês como AAAA-MM ou MM/AAAA e números com vírgula (ex.: 263,36). Meses existentes são atualizados; erros são listados linha a linha e as linhas corretas entram mesmo assim.
  6. O simulador passa a usar o valor imediatamente (a tabela sobrepõe a série embutida).

7Teste de ponta a ponta — checklist

  1. Tabelas: conferir que u_ndice_upf_e_selic, u_itcd_simulacao e u_u_itcd_avaliacao existem com todas as colunas da seção 2 (atenção: u_selic, u_qtd_doacoes, u_entrada, u_blocos com 8000).
  2. Widgets: abrir cada widget no Widget Editor e conferir a 1ª linha dos 4 painéis (tabela da seção 3). Salvar e usar o Preview (ícone de olho).
  3. Páginas: abrir /swp?id=simulador_itcd1 e /swp?id=citcd_admin logado na instância.
  4. Senha: no painel, senha errada não pode carregar nenhum dado; senha certa abre as 3 abas; Sair volta ao login.
  5. Índice: incluir um mês de teste (ex.: 2099-01, UPF 999, SELIC 9). Conferir na lista do painel e em /u_ndice_upf_e_selic_list.do. Incluir o mesmo mês com outro valor → deve atualizar, não duplicar. Remover o mês de teste ao final.
  6. Cálculo herança: no simulador, calcular uma herança (ex.: R$ 500.000, óbito em ano recente). Conferir demonstrativo (faixas, multa) e o registro em /u_itcd_simulacao_list.do com u_entrada e u_blocos preenchidos e totais iguais aos da tela.
  7. Cálculo 2+ doações: calcular com duas doações no mesmo ano; conferir o aviso "Regra de doações sucessivas", o acúmulo de faixas, e no registro u_qtd_doacoes = 2 com os dois blocos em u_blocos.
  8. Avaliação: enviar estrelas + comentário; conferir o "obrigado", o contador/média no rodapé do simulador e o registro na aba Avaliações do painel.
  9. Impressão: calcular → Imprimir: o PDF deve conter apenas o demonstrativo, com marca d'água diagonal, data/hora de emissão e a tarja "Documento gerado pelo simulador de ITCD — Sujeito a conferência no sistema oficial da SEFAZ-MT."
  10. Conta real do mantenedor: repetir os passos 4–5 logado com a conta do mantenedor (Conecta, sem perfil de desenvolvedor), confirmando que ele acessa, grava e vê os índices.
